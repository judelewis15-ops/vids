## Why there are no shot lists

A shot list has to come from watching the footage. I could not get the footage.

`pull_reels.py` works in three stages: scrape fresh CDN URLs, download the MP4s, then run ffmpeg and
Whisper over them. Stages 1 and 3 are fine here — the Apify scrape returned live URLs for all 8 reels,
and ffmpeg plus faster-whisper are installed and working in this container. Stage 2 is blocked.

This session's outbound traffic goes through a policy-enforcing egress proxy. Every Instagram CDN host
serving these videos returns **403 at CONNECT** — an organisation egress-policy denial, not a network
fault or an expired link:

    scontent-itm1-1.cdninstagram.com     scontent-fra5-1.cdninstagram.com
    scontent-iad3-1.cdninstagram.com     scontent-nrt6-1.cdninstagram.com
    scontent-muc2-1.cdninstagram.com     instagram.fpll9-1.fna.fbcdn.net
    instagram.fper5-1.fna.fbcdn.net      instagram.fsod9-1.fna.fbcdn.net

`api.apify.com` is blocked the same way, so pulling the videos out of an Apify key-value store is not a
way around it either. The proxy documentation is explicit that policy denials should be reported rather
than retried or routed around, so I stopped there.

The scripts in this document came from `apify/instagram-reel-scraper`, which downloads and transcribes
on Apify's own infrastructure and returns text through the connector. Text survives that path. Video
frames do not.

### What that costs you, specifically

The transcripts are a single unsegmented block per reel — the actor returns no word or sentence
timings. Running Whisper locally, as `pull_reels.py` does, would give timestamped segments, and those
timestamps are what let a script line be matched to the shot on screen at that moment. Without them,
even with the footage in hand, the two halves could only be aligned by eye.

### To get the shot lists

Run `pull_reels.py` unchanged on a machine with unrestricted network access. It already does
everything needed — frames every 2s into `out/{shortcode}/frames/` and word-level timestamped
transcripts. Set `APIFY_TOKEN` first, and note the CDN URLs in `out/reels.json` expire within hours,
so let the script do its own scrape rather than reusing them.

Alternatively, if these hosts can be added to this environment's egress allowlist, the whole pipeline
runs here as designed.
